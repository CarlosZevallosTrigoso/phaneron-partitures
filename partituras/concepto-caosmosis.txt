# Caosmosis
# Versión larga de «Neón», 35 minutos, sobre el concepto de Félix Guattari.
# En «Caosmosis» (1992), su último libro, el caos no es desorden: es un caos
# determinista animado por velocidades infinitas, del que se desprenden
# composiciones complejas cuando se ralentizan. Los ritornelos cristalizan
# territorios existenciales, que siguen habitados por el caos y vuelven a él;
# lo que se recompone después no es lo mismo (heterogénesis). La palabra viene
# del «chaosmos» de Joyce.
#
# El mapa logístico x → r·x·(1−x) es el caso de manual de caos determinista,
# y su parámetro r hace de forma de la pieza:
#   r < 3          un punto fijo: una sola nota, el primer ritornelo
#   r = 3          el punto se duplica: dos notas que alternan
#   r ≈ 3.449      cuatro notas; en 3.544, ocho; luego 16, 32…
#   r ≈ 3.5699     el borde del caos (punto de Feigenbaum): complejidad sin caos
#   r > 3.57       caos, con ventanas de orden; la mayor, de período 3, abre en 3.8284
#   justo antes de esa ventana hay intermitencia: el ciclo de tres notas se
#   forma y se deshace una y otra vez
#
# Forma, en minutos:
# 0–11   velocidad infinita: un polvo de campanas que sigue el mapa en caos
#        pleno (r = 4) a 14 notas por segundo y se ralentiza hasta 1,2.
# 3–19   ralentización: una cuerda sigue el mapa con r creciente: una nota,
#        dos, cuatro, ocho, hasta el borde, donde el ciclo llega a 32 corcheas
#        (4 compases, como el ritornelo del pad grave) y sigue alargándose sin
#        volverse caos.
# 6–29   territorio: el mundo de Neón se arma sobre esos ritornelos (pad grave,
#        campanas, pads de Nørgård y, entre los minutos 13 y 19, bajo y bombo).
# 17–27  caosmosis: otra cuerda, una octava abajo, parte del mismo borde y cae
#        al caos (r de 3.5699 a 4) mientras el territorio se deshace. Las dos
#        cuerdas empiezan en la misma órbita, a una octava, y se separan a los
#        pocos compases. Hacia el minuto 23 la caída cruza la ventana de
#        período 3: medio minuto de orden dentro del caos. El polvo vuelve a
#        acelerar hasta 9 notas por segundo.
# 25–35  heterogénesis: el polvo se ralentiza otra vez y unas campanas se
#        acercan a la ventana de período 3 desde abajo; el ciclo fa, re, do
#        aparece y se rompe cada vez menos hasta fijarse, cerca del minuto 33.
#        No vuelve el territorio de Neón: el nuevo suelo es fa,
#        no re, y el ciclo de tres va a contratiempo del compás de cuatro.
